# Roadmap

Where this hub is going. One stage at a time — a stage ships only when its
lessons are real, not outlines.

## Alpha — v0.1.0-alpha (now, 26 Nov 2026)

- [x] **Level 1 — Framework beginner path (4 lessons):** what Frappe is,
  bench/sites/apps, first DocType, Desk/List/Form.
- [x] **Core ERPNext modules (4 lessons):** Accounting, Stock, Selling,
  Buying — each with core DocTypes, end-to-end flow, a real use case and a
  "How we can use it" line.
- [x] **Guides:** Common mistakes (field layout, hooks, permissions,
  performance) with a pre-ship checklist.
- [x] **Research:** history of the last 2 years (18 items) + 66-app catalog
  in 11 per-category files.

## Beta — v0.2.0 (done, 26 Nov 2026)

- [x] **Levels 2–3 — Framework (12 lessons):** Server Scripts & Document
  Events, Client Scripts, APIs, Reports & Print Formats, Permissions &
  Roles, Workflows, Scheduler & Background Jobs, Notifications & Email,
  Testing, Performance, Security, Debugging.
- [x] **Remaining ERPNext modules (10 lessons):** Manufacturing, Quality,
  Projects, Assets, HR, CRM, Helpdesk, Support & Portal, Studio/Flow/
  Insights in v16, cross-module flows (forecast → MPS → MRP).
- [x] **Guides:** Upgrade guide (v14 → v15 → v16 readiness check) and Go-live
  checklist (data import, permissions, training, cutover).
- [x] **Polish:** every lesson reviewed against frappe_core_skills and the
  official docs; link check run (104 links, 1 intentional forward
  reference to Level 4, which is v1.0 scope).

## v1.0 (done, 26 Nov 2026)

- [x] **All 21 framework topics** written (Levels 1–4, including Studio & Flow,
  Insights, Website & Portal, Upgrades, Ops).
- [x] **All 14 ERPNext modules** written.
- [x] **All guides** written: upgrade, go-live, common mistakes, choosing apps.
- [x] **Research kept current:** history extended past Nov 2026, apps catalog
  updated as new apps land (from frappe-updates).
- A learner can go from zero to a production ERPNext implementation using
  only this hub plus the linked skills repo.

## Out of scope

- This hub teaches; it does not replace the official docs. Every lesson
  links to the deep reference
  ([frappe_core_skills](https://github.com/irfanzahoor/frappe_core_skills))
  and the official docs where detail lives.
- No video content planned. Text + commands + real examples only.
