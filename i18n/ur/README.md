## Yeh hub kaise organised hai

- **Learn** — tartib se learning paths. Pehle beginner, baad mein advanced. Har topic: yeh kya hai, kab use karna hai, aik minimal working example, aur common mistakes.
- **Research** — kya naya hai aur kya use karne ke qabil hai. Official Frappe Blog, Forum, GitHub releases, Frappe Times aur Marketplace se sourced, har item ke saath aik source link.
- **Guides** — opinionated, asal NexTash projects se: hum upgrades, go-lives, performance fixes aur custom apps asal mein kaise karte hain.
