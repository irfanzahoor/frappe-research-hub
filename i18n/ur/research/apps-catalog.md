## Gaps — jin ka pata hona chahiye


- **Pakistan payments (Easypaisa / JazzCash):** koi free public Frappe app maujood nahi hai. ECOSIRE ~$999 se build-to-order integration deta hai (https://ecosire.com/frappe-erpnext-payment-integration/). Local clients ke liye yeh sab se bara gap hai — Easypaisa/JazzCash ke liye ek Payment Core integration NexTash ke liye ek asli product opportunity hogi.
- **Official apps se aagay HR patla hai:** koi verified third-party recruitment/payroll app nahi mili; sirf Discipline HR aur biometric sync tool hai.
- **Official apps se aagay CRM patla hai:** koi verified standalone third-party Frappe CRM app nahi mili — market Frappe CRM par hi rely karti hai.
- **Not verified / propose karne se pehle verify karein:** WooCommerce Fusion, Medusa, South African Localisation, Italian e-invoicing, multi-country Peppol, Paymob/SumUp/Paystack — koi verified GitHub URL nahi mila. Print Designer v16 aur Insights v16 compatibility unconfirmed hai. KSA ZATCA repo URL case mismatch (entry dekhein). Frappe Learning/Builder ke exact bench commands — repo README mein verify karein.
