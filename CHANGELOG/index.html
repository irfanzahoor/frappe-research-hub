    Changelog¶

    All notable changes to the Frappe Research Hub. Dates are in Asia/Karachi.

    Unreleased¶

    Added¶

    • Docs website — the hub now reads as a website at https://irfanzahoor.github.io/frappe-research-hub/ (MkDocs Material: search, sidebar navigation, dark/light mode, dark-blue brand). mkdocs.yml + stylesheets/extra.css + scripts/sync-docs.sh build it from the repo's own markdown — no content is duplicated. Deployed to the gh-pages branch (GitHub Pages, branch source) by workspace/custom-connectors/custom.github-research-hub/bin/deploy_pages.py; redeploy after every content push until the token gains the Workflows permission, when .github/workflows/docs.yml (already written, not yet pushed — GitHub blocks workflow files for tokens without that permission) can take over auto-deploy.

    v1.0 — 2026-11-26¶

    The full path is written: all 21 Framework topics, all 14 ERPNext modules, all 4 guides. A learner can go from zero to a production ERPNext implementation using only this hub plus the linked skills repo.

    Added¶

    • Learn: Frappe Framework — Level 4 (5 lessons)
    • learn/framework/level-4/17-studio-flow.md — Studio mini-app (hands-on) and Flow (beta, permission-aware AI in Desk).
    • learn/framework/level-4/18-insights.md — Insights dashboards in Desk: Workbook, Query, Chart, Dashboard.
    • learn/framework/level-4/19-website-portal.md — Frappe Website, Web Forms, customer portal pages (www/, get_context).
    • learn/framework/level-4/20-upgrades.md — upgrades, lesson-length version (deep reference: upgrade guide).
    • learn/framework/level-4/21-ops.md — backups, monitoring, multi-site benches, Frappe Cloud vs self-hosted.
    • Guides
    • guides/choosing-apps.md — when to install an app vs build it: the 5 questions, install/build/extend, red flags, worked example, upgrade cost of every app.

    Fixed¶

    • Corrected the portal example in learn/framework/level-4/19-website-portal.md: Contact has no direct customer field — the Customer link lives in its Dynamic Link child table, resolved in two steps (verified against the Contact DocType in Frappe v16).
    • Aligned Frappe Flow's status to beta (official docs) in learn/erpnext/v16/13-studio-flow-insights.md — it was called alpha in the v16.60 launch notes; the history entry for the launch keeps the original wording.

    v0.1.0-alpha — 2026-11-26¶

    First real content. The beginner path is no longer an outline — it has lessons you can actually follow.

    Added¶

    • Learn: Frappe Framework — Level 1 (4 lessons)
    • learn/framework/level-1/01-what-is-frappe.md — Framework vs ERPNext vs Frappe Cloud.
    • learn/framework/level-1/02-bench-sites-apps.md — bench install, first site, first app (v16 commands).
    • learn/framework/level-1/03-first-doctype.md — your first DocType: fields, field types, layout rules (Section / Column Breaks, 2 fields per row, child table in its own section, max 4–5 list columns).
    • learn/framework/level-1/04-desk-list-form.md — Desk, List View, Form View: how users actually work.
    • Learn: ERPNext — Core modules (4 lessons)
    • learn/erpnext/core/01-accounting.md — Chart of Accounts, GL, invoicing, payments, tax.
    • learn/erpnext/core/02-stock-inventory.md — warehouses, batches, serials, FEFO, valuation.
    • learn/erpnext/core/03-selling.md — quotations, sales orders, delivery, pricing.
    • learn/erpnext/core/04-buying.md — purchase orders, receipts, supplier workflow (three-way match).
    • Every module lesson ends with a real use case and a "How we can use it" line for NexTash / client work.
    • Guides
    • guides/common-mistakes.md — field layout, hooks in the wrong place, permission mistakes, performance mistakes (N+1, missing indexes), ledger/stock rules, plus a pre-ship checklist.
    • Research — complete as of 26 Nov 2026
    • research/history-2024-2026.md — 18 major changes, Nov 2024–Nov 2026.
    • research/apps-catalog.md — 66 useful apps in 11 categories, each category in its own file under research/apps-catalog/.
