# Contributing

Yeh hub public hai taake koi bhi is se seekh sake. Changes sirf fork + pull request se, merge se pehle reviewed.

- Entries chhoti rakhein: kya, kab, kaise use karna hai, source link.
- Har claim ke liye source chahiye: official docs, Frappe Blog/Forum, GitHub release, ya aik tested example.
- Kabhi woh version promise na karein jo aap ne test nahi kiya.
- Aik file mein aik topic, pehle beginner.
