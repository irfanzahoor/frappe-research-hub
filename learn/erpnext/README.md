# Learn: ERPNext Modules — Noob to Pro

Each module: what it does, the core DocTypes, the end-to-end flow, and a real use case with a "How we can use it" line for NexTash / client work.

## Core
1. Accounting — Chart of Accounts, GL, invoicing, payments, tax
2. Stock & Inventory — warehouses, batches, serials, FEFO, valuation
3. Selling — quotations, sales orders, delivery, pricing
4. Buying — purchase orders, receipts, supplier workflow

## Operations
5. Manufacturing — BOM, Work Orders, Job Cards, production, subcontracting
6. Quality — inspections, QC quarantine / release / hold / reject
7. Projects — tasks, timesheets, costing
8. Assets — asset lifecycle, depreciation, maintenance

## People & customers
9. HR — employees, leave, payroll, attendance
10. CRM — leads, deals, web forms (use Frappe CRM, not legacy CRM)
11. Helpdesk — tickets, SLAs, support workflow
12. Support & Portal — customer portal, communication

## New in v16
13. Studio-built mini-apps, Flow (AI), Insights dashboards in Desk
14. Cross-module flows — forecast → MPS → MRP, sales → stock → accounts

Real-world example: [fmc](https://github.com/irfanzahoor/fmc) — Food Manufacturing for ERPNext. See Manufacturing + Quality + Stock in a real app.
